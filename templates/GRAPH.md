# 任务图（GRAPH）

> 当前活跃任务的拓扑视图。PMO 维护：**每次派发 / 状态变化时更新**。
> 节点 = 活跃任务（goal），边 = 依赖 / 交接（来自各 goal 的"依赖与边"字段）。
> 归档任务不画（历史不加载）。老板看这张图 = 一眼知道团队在怎么协作。

```mermaid
flowchart LR
    T1[Goal T1: <标题>] --> T2[Goal T2: <标题>]
    subgraph G1[并行组 G1]
        T2
        T3[Goal T3: <标题>]
    end
    T1 --> R1{Reviewer 验收}
    T2 --> R1
    T3 --> R1
    R1 -- 通过 --> M[合并 main]
    R1 -- 失败 --> T2
```

## 当前拓扑说明

- 并行：<G1 等任务同时开工>
- 串行/依赖：<T1 完成后 T2 才开工>
- 风险点：<哪条边可能冲突/失败/需要老板决策>
